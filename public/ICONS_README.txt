ICON REQUIREMENTS FOR PWA
========================

To complete the PWA setup, you need to add the following icon files to this directory:

1. icon-192.png (192x192 pixels)
   - A lime/green themed icon with "LG" or a lime emoji
   - Used for Android home screen and app drawer

2. icon-512.png (512x512 pixels)
   - Same design as icon-192, but higher resolution
   - Used for splash screens and high-DPI displays

DESIGN SUGGESTIONS:
- Background: Forest green (#2d5016) or lime gradient
- Icon: White "LG" letters or 🍋 emoji
- Make it simple and recognizable at small sizes

TOOLS TO CREATE ICONS:
- Figma (free): https://figma.com
- Canva (free): https://canva.com
- Favicon.io (online generator): https://favicon.io

After creating the icons, place them in /public/ directory:
- /public/icon-192.png
- /public/icon-512.png

The manifest.json is already configured to use these files.
